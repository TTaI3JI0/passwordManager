# PasswordManager

Консольное приложение для безопасного хранения паролей. 
Вы запоминаете только один мастер-пароль, а программа хранит все остальные в зашифрованном виде.

## Общая информация

1. При первом запуске вы придумываете мастер-пароль.
2. От него создаётся хэш (PBKDF2 + SHA256) и случайная соль (соль) — они сохраняются в файл. Сам мастер-пароль **нигде не хранится**.
3. Когда вы входите, программа считает хэш от введённого пароля и сравнивает с сохранённым. Если совпало — вы внутри.
4. Из того же мастер-пароля генерируется ключ шифрования (Fernet). Этим ключом шифруются пароли от сайтов.

## Установка и запуск

1. Установите [uv](https://docs.astral.sh/uv/).
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/TTaI3JI0/passwordManager.git
   cd passwordManager
3. Установите зависимости (это создаст папку `.venv` и скачает всё нужное):
   ```bash
   uv sync
4. Запуск:
    ```bash
   uv run python -m passwordmanager

## Предупреждения
1. Фича первая - восстановить мастер-пароль нельзя, если забудете, то доступ к данным не вернуть!
3. Фича вторая - если записать пароль на уже существующий ресурс, то пароль просто перезапишется.
